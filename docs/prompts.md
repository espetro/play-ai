# YouTube Video Prompt Taxonomy

Prompts users can make to the Play AI extension for working with YouTube videos.

## 📝 Core Summarization

1. "Summarize this video"
2. "Give me a 3-bullet summary"
3. "TL;DR of this video"
4. "What is this video about in one paragraph"
5. "Summarize the key points only"
6. "Break down this video chapter by chapter"

## 🎯 Targeted Extraction

7. "What tools/software are mentioned?"
8. "Extract all timestamps and topics"
9. "What are the main arguments?"
10. "What statistics or data points are shared?"
11. "List all resources/links mentioned"
12. "What questions does this video answer?"
13. "What prerequisites does this video assume?"

## ❓ Q&A / Comprehension

14. "Explain this video like I'm 5"
15. "What is the main thesis?"
16. "What's the controversy here?" (for debate videos)
17. "How does [specific concept] work?"
18. "What example is used to illustrate [topic]?"
19. "Is this video accurate/reliable?"

## 🔄 Transformation

20. "Convert this into a tweet thread"
21. "Write study notes from this video"
22. "Turn this into a LinkedIn post"
23. "Create a transcript with highlights"
24. "What would a 1-minute version sound like?"

## 📊 Analysis / Criticism

25. "What are the counter-arguments?"
26. "What is the video missing?"
27. "Compare this to [other video/article]"
28. "What claims need citation?"
29. "Is this advice safe to follow?"

## 📚 Learning Mode

30. "Quiz me on this video"
31. "Generate flashcards from this video"
32. "What should I Google to learn more?"
33. "What's the next video in this series?"
